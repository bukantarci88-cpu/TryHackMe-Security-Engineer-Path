#### **Task 1: Introduction**

Security engineers form the backbone of an enterprise’s cyber security posture. 

#### **Task 2: What is a Security Engineer?**

Organizations can either go back to the old ways of doing business without getting any aid from modern technology, putting them at a disadvantage, or they can move forward and ensure the security of the digital side of their business. 

**The Role of a Security Engineer**

- Owns the overall security of an organization. The main person responsible for securing an organization’s digital assets.
- Ensures that the organization’s cyber security risk is minimized at all times.
- Devises strategies and creates systems that minimize the risk posed by cyber security threats to an organization.
- Periodically conducts tests to ensure the robustness of the cyber security posture of an organization, identifies weak points, and prepares mitigations.
- Develops and implements secure network solutions.
- Architects and engineers trustworthy, reliable, and secure systems.
- Collaborates and coordinates with other teams to establish security protocols across the organization.

**Qualifications Required for a Security Engineer** Security engineers apply systematic problem-solving to security challenges, decomposing complex risks into actionable, solvable components.

- 0–2 years of experience with IT administration, helpdesk, networks or security operations.
- Basic understanding of computer networks, operating systems, and programming.
- Basic understanding of security concepts such as Governance, Risk and Compliance (GRC).

**Task 3: Core Responsibilities of a Security Engineer**

**Asset Management/Asset Inventory** This will mean managing and maintaining an inventory of an organization’s digital assets. Security engineers can only own an organization’s security if they know what assets the organization has. 

**Security Policies** Security engineers establish, roll out, and enforce organization-wide security policies grounded in core security principles.

**Secure by Design** Security engineers maximize ROI by building security into systems from the ground up, enforcing secure network architectures, system hardening, and a secure software development lifecycle.

**Security Assessment and Assurance** Security engineers manage third-party assessments, audits, and red/purple-team exercises from sourcing external vendors to prioritizing and remediating findings—to strengthen defenses against evolving threats.

#### **Task 4: Continuous Improvement**

**Ensuring Awareness** Security engineers run regular awareness training to defend against social engineering for all staff and enforce role-specific security practices for technical teams.

**Managing Risks** Security engineers help businesses maintain operations and avoid legal or financial damage by identifying, assessing, and mitigating essential risks, acknowledging that total elimination is impossible.

**Change Management** To ensure a robust security posture, the security engineer keeps track of changes in the organization’s digital assets that can affect the security posture and takes measures to improve the security posture with the organization’s evolution.  

**Vulnerability Management** The threat landscape is continuously evolving. New software versions are released, and vulnerabilities are found in the older versions. The security engineer’s job often includes monitoring vulnerabilities across the organization and planning to patch or minimize their risk.

**Compliance and Audits** Security engineers ensure adherence to industry standards (e.g., PCI-DSS, HIPAA, ISO27001) by collaborating with auditors to identify and resolve non-compliance risks.

#### **Task 5: Additional Roles and Responsibilities**

**Managing Security Tooling** Security engineers configure and fine-tune core security tools (SIEMs, Firewalls, EDRs) and evaluate competitive solutions to guide tool procurement decisions.

**Tabletop Exercises** Tabletop exercises are often conducted to gauge the operational readiness of an organization from a security point of view. Certain scenarios are identified to be exercised, and security team members must explain their respective roles in the scenarios under discussion. 

**Disaster Recovery and Crisis Management** Security engineers contribute to disaster recovery, business continuity, and crisis management planning to ensure operations resume quickly during disruptions while satisfying compliance standards.

**Task 7: Conclusion**

To conclude, we learned that a security engineer:

- Owns the responsibility of an organization’s cyber security.
